📥 Importación masiva

Para cargar muchos registros de golpe (en vez de uno a uno con "Nuevo X"), se rellenan unas hojas de trabajo (STG_*) directamente en el Sheet y luego se valida e importa todo junto.

1
Preparar las hojas de trabajo
Crea (si no existen ya) las hojas STG_CAMPANA, STG_PROYECTO, STG_PRODUCTO, STG_PROCESO, STG_TAREA, STG_RECURSO, STG_PERSONA y STG_EQUIPO_MIEMBRO, cada una con sus columnas ya tituladas. No borra ni toca hojas que ya tengas.
2
Rellenar las filas
En cada hoja STG_*, una fila por registro. ID_TEMPORAL es una referencia tuya dentro del mismo lote (p.ej. "P1"); las columnas que enlazan con el nivel padre (PROYECTO_TEMPORAL, PROCESO_TEMPORAL...) pueden apuntar a un ID_TEMPORAL de otra fila del lote, o a un ID real ya existente si estás ampliando algo que ya tenías creado. No toques ESTADO_IMPORTACION ni ID_REAL, los rellena el propio proceso. Puedes escribir a mano en el Sheet, o usar la plantilla + IA de abajo y subir el resultado.
3
Plantilla para rellenar con una IA
Descarga un .zip con un CSV vacío por hoja, un LEEME.txt con las columnas/campos obligatorios/valores de catálogo, y un PROMPT_IA.txt listo para pegar en una IA: abre una entrevista guiada (objetivo, alcance, procesos, tareas...) antes de generar nada, y te devuelve cada CSV ya relleno en el formato correcto.
4
Subir CSV ya rellenado
Sube uno o varios CSV con el mismo nombre que la hoja de destino (p.ej. STG_CAMPANA.csv). Se añaden al final de la hoja correspondiente; no borran ni tocan filas que ya tuvieras.
5
Importar Campaña → Proyecto → Producto → Proceso → Tarea
Valida todo primero (campos obligatorios, catálogos, que cada referencia exista) y te enseña un resumen antes de crear nada. Solo crea registros si confirmas.
6
Importar Recursos / Personas y equipos
Mismo criterio de validar-antes-de-crear, para las hojas STG_RECURSO, STG_PERSONA y STG_EQUIPO_MIEMBRO.
7
Importar Asignaciones (Responsable/Recurso a Tarea)
Pensado para ejecutarse después de crear las tareas (y, si hace falta, las personas/recursos): TAREA_TEMPORAL/PERSONA_TEMPORAL/RECURSO_TEMPORAL admiten un ID real o el mismo ID_TEMPORAL corto de un lote anterior, aunque ya esté importado.
8
Importar Decisiones / Incidencias / Documentos
Se pueden importar en cualquier momento después de crear la campaña -- cuelgan de un proyecto (Decisión) o de cualquier nivel de la jerarquía (Incidencia/Documento).
9
Importar Horarios
Franjas semanales de personas/equipos o recursos. Necesario para que "Calidad de planificación" pueda calcular la utilización de horario.
