📥 Importación masiva

Para cargar muchos registros de golpe (en vez de uno a uno con "Nuevo X"), se rellenan unas hojas de trabajo (STG_*) directamente en el Sheet y luego se valida e importa todo junto.

1
Preparar las hojas de trabajo
Crea (si no existen ya) las hojas STG_CAMPANA, STG_PROYECTO, STG_PRODUCTO, STG_PROCESO, STG_TAREA, STG_RECURSO, STG_PERSONA y STG_EQUIPO_MIEMBRO, cada una con sus columnas ya tituladas. No borra ni toca hojas que ya tengas.
2
Rellenar las filas a mano
En cada hoja STG_*, una fila por registro. ID_TEMPORAL es una referencia tuya dentro del mismo lote (p.ej. "P1"); las columnas que enlazan con el nivel padre (PROYECTO_TEMPORAL, PROCESO_TEMPORAL...) pueden apuntar a un ID_TEMPORAL de otra fila del lote, o a un ID real ya existente si estás ampliando algo que ya tenías creado. No toques ESTADO_IMPORTACION ni ID_REAL, los rellena el propio proceso.
3
Importar Campaña → Proyecto → Producto → Proceso → Tarea
Valida todo primero (campos obligatorios, catálogos, que cada referencia exista) y te enseña un resumen antes de crear nada. Solo crea registros si confirmas.
4
Importar Recursos / Personas y equipos
Mismo criterio de validar-antes-de-crear, para las hojas STG_RECURSO, STG_PERSONA y STG_EQUIPO_MIEMBRO.
