Mapa -- jerarquía real de Índice

Columnas = todas las páginas reales de Índice. Tarjetas = sus cajas reales (Proceso). Las páginas 🔒 son reales pero hechas a mano -- se ven en solo lectura, nunca arrastrables (reconstruirlas sobrescribiría su contenido real de verdad). Solo las creadas con Arquitecto se pueden mover/reordenar de verdad. Arrastra una tarjeta dentro de su columna para reordenarla (se guarda sola, bajo riesgo -- usa el campo real ORDEN_SECUENCIA). Arrástrala a otra columna para moverla de página de verdad (pide confirmación explícita y reconstruye las DOS páginas reales afectadas). Para crear páginas nuevas o editar el contenido real de una caja, usa Arquitecto -- aquí solo se configura la jerarquía. Para ver Índice dentro del árbol real completo (con todas las demás Campañas/Proyectos reales), ábrelo directamente aquí.
