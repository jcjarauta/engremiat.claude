Mapa -- jerarquía real de Índice

Árbol real de Índice: Proyecto → Producto (página) → Proceso (caja) → Tarea. Las páginas 🔒 son reales pero hechas a mano -- se ven en solo lectura, nunca arrastrables (reconstruirlas sobrescribiría su contenido real de verdad). Solo las páginas creadas con Arquitecto admiten arrastrar sus cajas: dentro del mismo Producto para reordenar (se guarda sola, bajo riesgo -- usa el campo real ORDEN_SECUENCIA), o a otro Producto para moverla de página de verdad (pide confirmación explícita y reconstruye las DOS páginas reales afectadas). El botón "Ejecutar ahora" que aparece después necesita node servidor_aplicar_local.mjs arrancado en tu máquina (escucha solo en 127.0.0.1) -- sin él, aplica el cambio a mano con el comando de siempre. Para crear páginas nuevas o editar el contenido real de una caja, usa Arquitecto. Para ver Índice dentro del árbol completo (con todas las demás Campañas/Proyectos reales), ábrelo directamente aquí.
