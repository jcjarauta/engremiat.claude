Grafos del sistema

Índice real por tipo -- cada grafo del visor visualiza una parte concreta del sistema (§8.87-96, PROPUESTA_BASTIDOR_GESTOR_PROYECTOS_ENGREMIAT.md). Taxonomía real, no inventada: los mismos tipos ya establecidos en tools/gobierno/bocetador/schemas/ y en 01_Mundo/ del vault (Espacio/Personaje/Recurso/Módulo/Herramienta/Regla). Las tarjetas se generan solas, en vivo, desde fichas_grafos.json -- cada extractor real escribe su propia ficha al terminar (§8.93); nada de esto se edita a mano. Solo el grafo inicial queda a la vista; el resto se pliega para no saturar la pantalla. Complementa a indice.html (lista técnica plana).

Constructor de grafos

Pega la URL de un JSON real ya generado (misma forma que todos los grafo_*.json de este visor: {"nodos":[...], "aristas":[...]}) o la URL de cualquier página HTML propia -- tres pasos reales, en orden, nunca un modelo interpretando contenido: (1) ¿es JSON directo?, (2) si no, ¿qué .json carga de verdad esa página? (§8.105), (3) si tampoco, se extrae en vivo un grafo real de sus propios enlaces reales a otras páginas y llamadas reales a la API -- mismo método real que usa mapear_grafo_visor.mjs (§8.83, §8.108), aplicado aquí a una sola página en vez de a las 25 de golpe. Se renderiza con la plantilla ya establecida. Vista previa efímera -- para conservarla de verdad, sigue el ciclo real ya existente (proponer_candidato.mjs → "A promover" más abajo). El mapa combinado de las 25 páginas (grafo_visor.json) lo sigue manteniendo la tarea programada real (§8.94).
