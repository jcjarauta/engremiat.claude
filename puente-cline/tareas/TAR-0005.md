# TAR-0005 -- Arreglar exportación CSV/PDF de Bloqueos (campos obsoletos)

## Contexto

`src/PanelTemporalService.js` generaliza `obtenerBloqueosPanelTemporal_()`
(sobre la línea 221) para que cada bloqueo tenga `{tipo, entidad,
entidadId, entidadNombre, detalle}` -- `entidad` es el nombre MVP real
(TAREA, DECISION, INCIDENCIA, MATERIAL, PEDIDO_PROVEEDOR...), no siempre
TAREA. El panel interactivo (`src/PanelTemporal.html`, función
`renderBloqueos_`, sobre la línea 304) ya usa correctamente
`b.entidad`/`b.entidadId`/`b.entidadNombre`.

Pero DOS exportaciones se quedaron con los nombres de campo antiguos
(`tareaId`/`tareaNombre`), que ya no existen en el objeto -- por eso
salen vacíos/`undefined`:

1. **Exportación CSV** (dentro de `src/PanelTemporalService.js`, busca el
   bloque que arma `bloquesCsv` con `titulo: 'Bloqueos'`, columna
   `encabezados: ['Tipo', 'Tarea', 'Detalle']` y la línea que hace
   `filas: datos.bloqueos.map(function (b) { return [b.tipo,
   b.tareaNombre, b.detalle]; })`).
2. **Exportación PDF/informe imprimible** (mismo archivo, función que
   construye `bloqueosHtml`, con la línea `'<tr><td>' +
   enlaceEdicion_('TAREA', b.tareaId, b.tareaNombre) + '</td><td>' +
   escaparHtmlServer_(b.detalle) + '</td></tr>'`).

## Resultado esperado

1. En la exportación CSV: cambiar `b.tareaNombre` por `b.entidadNombre`.
2. En la exportación PDF: cambiar `enlaceEdicion_('TAREA', b.tareaId,
   b.tareaNombre)` por `enlaceEdicion_(b.entidad, b.entidadId,
   b.entidadNombre)` -- así el enlace abre la ficha correcta según el
   tipo real de bloqueo, no siempre Tarea.

## Criterios de aceptación

- Solo se toca `src/PanelTemporalService.js`.
- No se cambia la cabecera `['Tipo', 'Tarea', 'Detalle']` del CSV (el
  nombre de columna "Tarea" se queda igual aunque ahora pueda contener
  el nombre de una Decisión/Incidencia/Material -- eso es cosmético, no
  forma parte de este arreglo).
- No se toca `PanelTemporal.html` (ya está correcto, es la referencia).
- No se toca `obtenerBloqueosPanelTemporal_()` ni la forma del objeto
  bloqueo -- el problema es solo en cómo lo LEEN las dos exportaciones,
  no en cómo se genera.
