# INC-0014 -- Importador masivo rechaza STG_EJECUCION_TAREA.csv

## Contexto

`src/ImportacionMasivaInicio.html`. El array `HOJAS_STAGING_CONOCIDAS_`
(línea 395) lista las hojas staging que el importador reconoce, pero le
falta `STG_EJECUCION_TAREA` -- el grupo Ejecución está completamente
cableado en el resto del sistema (validación, confirmación, plantilla,
backend), pero un usuario que arrastra `STG_EJECUCION_TAREA.csv` recibe
"nombre no reconocido" sin ninguna pista de por qué. El texto de ayuda de
la pantalla también dice "14 hojas" cuando en realidad ya son 15 con esta.

## Resultado esperado

1. En el array `HOJAS_STAGING_CONOCIDAS_` (líneas 395-400), añadir
   `'STG_EJECUCION_TAREA'` como un elemento más de la lista (el orden no
   importa, pero no borres ni cambies ninguno de los 14 ya existentes):

```
      var HOJAS_STAGING_CONOCIDAS_ = [
        'STG_CAMPANA', 'STG_PROYECTO', 'STG_PRODUCTO', 'STG_PROCESO', 'STG_TAREA',
        'STG_RECURSO', 'STG_PERSONA', 'STG_EQUIPO_MIEMBRO',
        'STG_TAREA_RESPONSABLE', 'STG_TAREA_RECURSO',
        'STG_DECISION', 'STG_INCIDENCIA', 'STG_DOCUMENTO', 'STG_HORARIO',
        'STG_EJECUCION_TAREA'
      ];
```

2. En el texto de ayuda (línea 101), cambiar "14 hojas" por "15 hojas":

```
          Crea (si no existen ya) las 14 hojas <code>STG_*</code>, cada una con sus columnas ya
```
->
```
          Crea (si no existen ya) las 15 hojas <code>STG_*</code>, cada una con sus columnas ya
```

## Criterios de aceptación

- Solo se tocan esos dos puntos, en `src/ImportacionMasivaInicio.html`.
- No se borra ni modifica ninguna de las 14 hojas ya listadas.
- No se toca `detectarHojaDestino_` ni ninguna otra función.

1. Cambios hechos en `src/ImportacionMasivaInicio.html`.
