# INC-0025 -- Idempotencia por-primer-valor en 3 instaladores (mismo fix ya aplicado en Ventas)

## Contexto

`InstaladorOportunidadL4.js`, `InstaladorClienteL4.js` e `InstaladorComprasL4.js`
tienen el MISMO bloque, cada uno en su propia función `instalarCatalogoXL4`:
solo comprueban si el PRIMER valor de una categoría ya existe en
`90_CONFIGURACION` -- si existe, dan la categoría entera por completa y se
saltan el resto. `InstaladorVentasL4.js` ya se corrigió a un filtro por
valor individual (INC-0012, ya aplicado y publicado) -- aplica exactamente
el mismo cambio a los otros 3 ficheros.

Código actual, IDÉNTICO en los 3 ficheros (cambian solo los números de línea):
- `InstaladorOportunidadL4.js` líneas 81-93
- `InstaladorClienteL4.js` líneas 77-89
- `InstaladorComprasL4.js` líneas 103-115

```
      var categoria = par[0];
      var valores = par[1];

      if (clavesExistentes_[categoria + '::' + valores[0][0]]) {
        console.log('OK ' + categoria + '_ya_completo=true');
        return;
      }

      var filas = valores.map(function (valor) {
        maxNumero += 1;
        anadidas.push('CFG-' + String(maxNumero).padStart(4, '0') + ':' + categoria + '/' + valor[0]);
        return ['CFG-' + String(maxNumero).padStart(4, '0'), categoria, valor[0], valor[1], '', '', 'SÍ', ahora, usuario, ahora, usuario];
      });
```

## Resultado esperado

En LOS 3 FICHEROS, cambiar ese mismo bloque a:

```
      var categoria = par[0];
      var valores = par[1];

      var valoresFaltantes = valores.filter(function (valor) {
        return !clavesExistentes_[categoria + '::' + valor[0]];
      });

      if (valoresFaltantes.length === 0) {
        console.log('OK ' + categoria + '_ya_completo=true');
        return;
      }

      var filas = valoresFaltantes.map(function (valor) {
        maxNumero += 1;
        anadidas.push('CFG-' + String(maxNumero).padStart(4, '0') + ':' + categoria + '/' + valor[0]);
        return ['CFG-' + String(maxNumero).padStart(4, '0'), categoria, valor[0], valor[1], '', '', 'SÍ', ahora, usuario, ahora, usuario];
      });
```
