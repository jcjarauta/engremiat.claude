# INC-0015 -- obtenerModulosDisponibles_ debe excluir APROVISIONAMIENTO/CORE igual que su hermana

## Contexto

`src/AprovisionamientoService.js`. Hay dos funciones que listan módulos
instalables:

- `obtenerModulosDisponiblesParaSolicitud` (línea 97) SÍ excluye
  `APROVISIONAMIENTO` y `CORE` explícitamente (con comentario explicando
  por qué: no son módulos para dar a un cliente sin decisión aparte).
- `obtenerModulosDisponibles_` (línea 414), usada por "Añadir módulo" en
  Gestión remota de clientes, NO tiene ese filtro -- permite añadir
  APROVISIONAMIENTO a cualquier cliente existente.

Código actual de `obtenerModulosDisponibles_` (líneas 414-416):
```
function obtenerModulosDisponibles_() {
  return Object.keys(PACKAGE_MAP_EMBEBIDO.moduleDependencies || {}).sort();
}
```

## Resultado esperado

Aplicar el mismo filtro que ya usa `obtenerModulosDisponiblesParaSolicitud`:

```
function obtenerModulosDisponibles_() {
  return Object.keys(PACKAGE_MAP_EMBEBIDO.moduleDependencies || {})
    .filter(function (m) { return m !== 'APROVISIONAMIENTO' && m !== 'CORE'; })
    .sort();
}
```

## Criterios de aceptación

- Solo se toca esa función, en `src/AprovisionamientoService.js`.
- No se toca `obtenerModulosDisponiblesParaSolicitud` (es la referencia
  correcta, no se modifica).
- No se toca `obtenerClientesConScriptId_` ni `obtenerDatosGestionRemotaClientes`.

## Definition of done

1. Cambio hecho en `src/AprovisionamientoService.js`.
2. Mensaje final con el formato ESTADO/RESUMEN/ARCHIVOS/GATES de `.clinerules`.
