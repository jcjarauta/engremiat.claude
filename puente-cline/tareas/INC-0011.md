# INC-0011 -- Movimiento de stock: avisar si el material no se resuelve

## Contexto

`src/StockMaterialService.js`, función `aplicarMovimientoAStock_` (línea 40).
Si `obtenerRegistroPorId('MATERIAL', materialId)` no encuentra el material,
la función hace `return` en silencio (línea 45) -- pero esto se llama
DESPUÉS de que la transacción que lo originó ya se confirmó, así que el
libro de movimientos queda desincronizado del stock real sin ningún aviso.

Código actual (líneas 44-45):
```
  var material = obtenerRegistroPorId('MATERIAL', materialId);
  if (!material) return;
```

## Resultado esperado

Registrar un aviso antes de salir, ya que la transacción que originó esta
llamada no se puede deshacer desde aquí:

```
  var material = obtenerRegistroPorId('MATERIAL', materialId);
  if (!material) {
    console.warn('aplicarMovimientoAStock_: material no encontrado, stock desincronizado. materialId=' + materialId + ' tipoMovimiento=' + tipoMovimiento);
    return;
  }
```

## Criterios de aceptación

- Solo se toca ese bloque (líneas 44-45), en `src/StockMaterialService.js`.
- El caso normal (material válido) no cambia de comportamiento.
- No se toca el resto de la función.

## Definition of done

1. Cambio hecho en `src/StockMaterialService.js`.
2. Mensaje final con el formato ESTADO/RESUMEN/ARCHIVOS/GATES de `.clinerules`.
