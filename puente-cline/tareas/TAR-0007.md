# TAR-0007 -- Mostrar cuántos hijos tiene un nodo sin desplegarlo (Panel de Campaña)

## Contexto

`ROADMAP_BACKLOG_MEJORAS.md` (línea 181) documenta un hallazgo real
todavía sin cerrar: en el árbol de `src/PanelCampana.html`, un nodo
Proceso o Proyecto no deja ver cuántos hijos tiene (tareas / productos)
sin desplegar el `<details>` -- hay que abrir cada nodo uno a uno para
saberlo.

Busca en `src/PanelCampana.html` las funciones `renderProceso` y
`renderProyecto`.

## Resultado esperado

Añadir el número de hijos junto al nombre del nodo, ANTES del badge de
estado, en estos dos sitios exactos:

1. En `renderProceso`, la línea que arma `nombre-nodo`:
```
'<div class="fila-superior"><span class="nombre-nodo">' + escapeHtml(proceso.nombre) + ' ' + renderBadge_(proceso.estado) + renderDetalle_(proceso) + '</span></div>' +
```
Insertar `' <span class="detalle-nodo">(' + proceso.tareas.length + ' tareas)</span>'` justo después de `escapeHtml(proceso.nombre)` y antes de `renderBadge_`.

2. En `renderProyecto`, la línea equivalente:
```
'<div class="fila-superior"><span class="nombre-nodo">' + escapeHtml(proyecto.nombre) + ' ' + renderBadge_(proyecto.estado) + renderDetalle_(proyecto) + '</span></div>' +
```
Insertar `' <span class="detalle-nodo">(' + proyecto.productos.length + ' productos)</span>'` justo después de `escapeHtml(proyecto.nombre)` y antes de `renderBadge_`.

`detalle-nodo` ya es una clase CSS existente en el mismo fichero (la usa
`renderDetalle_`) -- no hace falta añadir estilo nuevo.

## Criterios de aceptación

- Solo se tocan esas dos líneas concretas, en `src/PanelCampana.html`.
- No se toca `renderProducto` (el roadmap solo pide Proceso y Proyecto,
  no Producto -- no ampliar el alcance).
- No se toca `renderDetalle_` ni ninguna otra función.
- El conteo usa exactamente `.length` sobre el array ya existente
  (`proceso.tareas`, `proyecto.productos`) -- no se inventa ningún
  campo ni llamada nueva al servidor.
