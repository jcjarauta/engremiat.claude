# INC-0012 -- instalarCatalogoVentasL4: comprobar cada valor, no solo el primero

## Contexto

`src/InstaladorVentasL4.js`, función `instalarCatalogoVentasL4` (línea 12).
El bucle que añade categorías nuevas a `90_CONFIGURACION` (líneas 86-103)
solo comprueba si el PRIMER valor de la categoría ya existe
(`valores[0][0]`) -- si existe, da la categoría entera por completa y se
salta el resto. Si una ejecución previa quedó a medias, los valores
restantes de esa categoría nunca se insertan y no hay ningún error visible.

Código actual (líneas 86-103):
```
    categoriasNuevas.forEach(function (par) {
      var categoria = par[0];
      var valores = par[1];

      if (clavesExistentes_[categoria + '::' + valores[0][0]]) {
        console.log('OK ' + categoria + '_ya_completo=true');
        return;
      }

      var filas = valores.map(function (valor) {
        maxNumero += 1;
        anadidas.push('CFG-' + String(maxNumero).padStart(4, '0') + ':' + categoria + '/' + valor[0]);
        return ['CFG-' + String(maxNumero).padStart(4, '0'), categoria, valor[0], valor[1], '', '', 'SÍ', ahora, usuario, ahora, usuario];
      });

      hojaConfig.getRange(hojaConfig.getLastRow() + 1, 1, filas.length, filas[0].length).setValues(filas);
      console.log('OK ' + categoria + '_filas_anadidas=' + filas.length);
    });
```

## Resultado esperado

Filtrar `valores` para quedarse solo con los que YA NO existen (por clave
individual, `categoria + '::' + valor[0]`), e insertar solo esos:

```
    categoriasNuevas.forEach(function (par) {
      var categoria = par[0];
      var valores = par[1];

      var valoresFaltantes = valores.filter(function (valor) {
        return !clavesExistentes_[categoria + '::' + valor[0]];
      });

      if (valoresFaltantes.length === 0) {
        console.log('OK ' + categoria + '_ya_completo=true');
        return;
      }

      var filas = valoresFaltantes.map(function (valor) {
        maxNumero += 1;
        anadidas.push('CFG-' + String(maxNumero).padStart(4, '0') + ':' + categoria + '/' + valor[0]);
        return ['CFG-' + String(maxNumero).padStart(4, '0'), categoria, valor[0], valor[1], '', '', 'SÍ', ahora, usuario, ahora, usuario];
      });

      hojaConfig.getRange(hojaConfig.getLastRow() + 1, 1, filas.length, filas[0].length).setValues(filas);
      console.log('OK ' + categoria + '_filas_anadidas=' + filas.length);
    });
```

## Criterios de aceptación

- Solo se toca ese bloque (líneas 86-103), en `src/InstaladorVentasL4.js`.
- Una categoría ya completa (todos sus valores presentes) no debe
  duplicar nada al reejecutar.
- No se toca el resto de la función (cálculo de `clavesExistentes_`,
  `asegurarRangosNombradosCatalogo_`, etc.).
