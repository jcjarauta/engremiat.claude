# INC-0010 -- FichaProveedor CSV: usar un identificador en Nombre, no la fecha cruda

## Contexto

`src/FichaProveedorService.js`, función `exportarFichaProveedorCSV` (línea 101).
Al construir la fila CSV de cada Pedido, pone `p.fechaPedido` (fecha ISO
cruda) en la columna "Nombre" -- el resto de exportadores de Fichas usan un
identificador legible en esa columna, no una fecha.

Código actual (línea 111):
```
    filas.push(['Pedido', p.id, p.fechaPedido, p.numeroLineas + ' líneas · ' + p.total + ' €', p.estado]);
```

## Resultado esperado

Cambiar esa línea para que la columna "Nombre" sea `'Pedido ' + p.id` y la
fecha se mueva a la columna "Detalle", junto con lo que ya había ahí:

```
    filas.push(['Pedido', p.id, 'Pedido ' + p.id, p.fechaPedido + ' · ' + p.numeroLineas + ' líneas · ' + p.total + ' €', p.estado]);
```

## Criterios de aceptación

- Solo se toca esa línea, en `src/FichaProveedorService.js`.
- No se toca el bloque de `datos.materiales.forEach` ni ninguna otra función.

## Definition of done

1. Cambio hecho en `src/FichaProveedorService.js`.
2. Mensaje final con el formato ESTADO/RESUMEN/ARCHIVOS/GATES de `.clinerules`.
